# Бот модерации Alem Mod — запуск в Termux (Android)

Бот работает через long polling — сам спрашивает Telegram "есть новое?",
поэтому НЕ нужен белый IP, домен, порты или root. Обычный телефон с
Termux и мобильным интернетом/wifi подходит полностью.

## Шаг 1. Создать бота в Telegram

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и юзернейм (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH...` — сохраните его, он понадобится дважды:
   в `.env` сайта (`TELEGRAM_BOT_TOKEN`) и в `.env` этого бота (`BOT_TOKEN`).
4. Если хотите ещё и вход на сайт через Telegram (кнопка на странице логина) —
   отправьте боту `/setdomain` и укажите домен вашего сайта.

## Шаг 2. Установить Termux и Node.js

1. Поставьте **Termux** из F-Droid (в Google Play он устаревший и не обновляется:
   https://f-droid.org/packages/com.termux/).
2. Откройте Termux и выполните:
   ```
   pkg update -y && pkg upgrade -y
   pkg install -y nodejs-lts git
   ```
3. Проверьте версию (нужна 18 и выше):
   ```
   node -v
   ```

## Шаг 3. Скопировать бота на телефон

Проще всего — скачать zip с кодом сайта (там же, где и весь `mod-hub`), закинуть
его на телефон (через Telegram "Избранное", Google Drive, USB-кабель — как
удобно) и распаковать:
```
pkg install -y unzip
cd ~
unzip /sdcard/Download/mod-hub.zip -d mod-hub
cd mod-hub/telegram-bot
```
(Если Termux не видит `/sdcard` — сначала `termux-setup-storage` и разрешите доступ к файлам.)

Если вместо этого сайт лежит у вас на VPS в git-репозитории — просто
`git clone` его и зайдите в папку `telegram-bot` тем же способом на VPS
(там всё то же самое, только через SSH вместо Termux).

## Шаг 4. Настроить .env

```
cp .env.example .env
nano .env
```
Впишите:
- `BOT_TOKEN` — токен из шага 1
- `SITE_URL` — адрес вашего сайта, например `https://alemmod.up.railway.app` (без `/` на конце)
- `BOT_API_SECRET` — придумайте длинную случайную строку (например `openssl rand -hex 32`,
  если команда есть, или просто нахлопайте по клавиатуре 32+ случайных символов).
  **Точно такую же строку** впишите в `.env` сайта, в переменную `BOT_API_SECRET`.

Сохраните файл: `Ctrl+O`, `Enter`, затем `Ctrl+X`.

На сайте (в его собственном `.env`, не в этом) должны быть заданы:
```
TELEGRAM_BOT_TOKEN=тот же токен
TELEGRAM_ADMIN_CHAT_ID=ваш chat_id (узнаете на следующем шаге)
BOT_API_SECRET=тот же секрет, что и здесь
```
После правки `.env` сайт нужно перезапустить, чтобы переменные подхватились.

## Шаг 5. Запустить бота и узнать свой chat_id

```
node bot.js
```
Должно появиться `[bot] Alem Mod бот запущен, слушаю сообщения...`.

Теперь в Telegram откройте вашего бота и отправьте `/start` — он пришлёт
ваш `chat_id`. Впишите его:
- в `ADMIN_CHAT_IDS` в этом `.env` (только что редактировали),
- в `TELEGRAM_ADMIN_CHAT_ID` в `.env` сайта.

Перезапустите и бота (`Ctrl+C`, потом снова `node bot.js`), и сам сайт.

Проверка: отправьте боту `/pending` — он покажет всё, что сейчас висит на
модерации, с кнопками «Одобрить» / «Отклонить». А когда кто-то опубликует
новый мод на сайте — уведомление с такими же кнопками прилетит само.

## Кнопки перезапуска (`/restart`) — только если бот стоит на VPS

Команда `/restart` в боте показывает три кнопки: «Сайт», «Сервер (весь
VPS)», «Оба» — после подтверждения бот **локально** выполняет команды из
`SITE_RESTART_CMD` (`pm2 restart mod-hub` по умолчанию) и
`SERVER_REBOOT_CMD` (полная перезагрузка VPS, а не просто рестарт какого-то
сервиса). Специально локально, не через HTTP на сайт: если сайт завис
(классика после пары дней аптайма — как раз 502 от nginx), запрос через
HTTP до него мог бы и не дойти. Поэтому **кнопки работают, только если бот
запущен прямо на VPS** — в Termux на телефоне выполнять там нечего.

Кнопка «Сервер» — это **полная перезагрузка всей машины** (`reboot`), а не
просто перезапуск какого-то одного сервиса. При этом виртуалка полностью
перезагружается вместе с самим ботом — на несколько десятков секунд бот
пропадёт из сети, это нормально. Чтобы он **сам вернулся** после ребута
(а не остался просто не запущенным), бота тоже нужно запускать через pm2 с
включённым автозапуском — это уже описано ниже в разделе «То же самое, но
на VPS»: `pm2 start bot.js --name alem-mod-bot` + `pm2 save` + `pm2 startup`.
Без этого после перезагрузки VPS поднимется, а вот бот — нет, и его придётся
запускать руками через SSH.

Перезагрузка требует **sudo без пароля**, но только на одну эту команду —
давать боту полный sudo не нужно и опасно. Настройка:
```
sudo visudo -f /etc/sudoers.d/alem-mod-bot
```
Впишите одну строку (замените `youruser` на пользователя, от которого
запущен бот, посмотреть — командой `whoami`):
```
youruser ALL=(root) NOPASSWD: /usr/bin/systemctl reboot
```
Сохраните (`Ctrl+O`, `Enter`, `Ctrl+X`) — `visudo` сам проверит синтаксис
перед сохранением, это безопаснее, чем редактировать `/etc/sudoers` напрямую.

## Шаг 6. Чтобы бот работал постоянно (не только пока открыт Termux)

Android любит "убивать" фоновые приложения ради экономии батареи — без
этих двух вещей бот рано или поздно остановится:

1. **Termux:Boot** (отдельное приложение, тоже с F-Droid) — автозапуск при
   перезагрузке телефона. После установки создайте файл
   `~/.termux/boot/start-bot.sh`:
   ```
   mkdir -p ~/.termux/boot
   cat > ~/.termux/boot/start-bot.sh << 'EOF'
   #!/data/data/com.termux/files/usr/bin/sh
   cd ~/mod-hub/telegram-bot
   node bot.js >> ~/telegram-bot.log 2>&1 &
   EOF
   chmod +x ~/.termux/boot/start-bot.sh
   ```

2. **Отключить экономию батареи для Termux**: Настройки Android → Приложения →
   Termux → Батарея → "Без ограничений" (формулировка зависит от прошивки).
   Иначе Android будет усыплять процесс, даже если он запущен.

3. Держать сессию живой, пока сами не выключили — используйте `tmux`, чтобы
   бот не остановился при закрытии окна Termux:
   ```
   pkg install -y tmux
   tmux new -s bot
   cd ~/mod-hub/telegram-bot && node bot.js
   ```
   Свернуть сессию (бот продолжит работать): `Ctrl+B`, затем `D`.
   Вернуться к ней позже: `tmux attach -t bot`.

   Также полезно `termux-wake-lock` (не даёт Android усыпить CPU, пока
   Termux открыт) — идёт в комплекте, просто выполните эту команду один раз
   в сессии перед запуском бота.

## То же самое, но на VPS (не Termux)

Всё то же самое, только вместо Termux — обычный SSH. Вместо `tmux` +
`Termux:Boot` проще поставить `pm2`:
```
npm install -g pm2
cd ~/mod-hub/telegram-bot
pm2 start bot.js --name alem-mod-bot
pm2 save
pm2 startup   # выполнит команду, которую покажет — она включит автозапуск pm2 при перезагрузке VPS
```
Логи: `pm2 logs alem-mod-bot`. Перезапуск после правки `.env`: `pm2 restart alem-mod-bot`.

Именно этот вариант (бот на VPS) нужен, чтобы работали кнопки `/restart` —
раздел «Кнопки перезапуска» выше.
