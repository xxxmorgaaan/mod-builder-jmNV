Как создать мод

Коротко: пишете название — остальное конструктор в большинстве случаев подставляет сам. Ниже — по шагам.

Уже есть готовый мод в архиве .zip? Кнопка «Загрузить мод (.zip)» внизу левой колонки откроет его прямо здесь для редактирования — не нужно собирать заново с нуля.

  1. 1. Вкладка «Мод»

    Впишите id (латиницей, уникальный) и название мода. Это единственное, что обязательно на этой вкладке — автор, версия и описание необязательны.

  2. 2. Добавляйте вещи — только «Название»

    На вкладках «Оружие», «Одежда», «Ресурсы», «Рецепты», «Технологии» обязательно только поле «Название». Всё остальное можно не трогать:

    • id конструктор сделает из названия сам («Кылыш» → kylysh).
    • У оружия сверху есть выпадающий «Шаблон» (нож, меч, копьё…) — подставит характеристики. Не выбрали шаблон и не тронули поля — конструктор всё равно даст безопасные значения по умолчанию.
    • У одежды сама подставится слот (Torso), материал, прочность и номер картинки (look) — без коллизий с другими вашими вещами (два костюма в одном слоте не могут делить один look: занят 3 — следующий получит 4).
    • «Материал» и «доп. материалы» — не текст, а список: готовые ресурсы игры (дерево, железо, ткань, кожа…) плюс ваши уже добавленные, плюс «+ Новый ресурс» тут же на месте.
    • Черновая строка в «Перевод» появляется сама, как только вписано название.

  3. 3. Откройте вещь в технологиях

    Под формой оружия/одежды/рецепта/постройки есть блок «⚙ Открыть в технологиях». Выберите существующую технологию или нажмите «+ Создать новую» и впишите только название — ключ доступа конструктор впишет сам. Без этого вещь останется в таблице, но её нельзя будет сделать в игре.

    Для построек/кроватей/стен/энергии/осадных орудий/культур/механик, у которых нет своей вкладки — на вкладке «Технологии» в поле «Открывает ключи» есть тот же конструктор: выбрали тип (building, bed, wallmat, power, siege, crop, mech…), вписали id или имя — ключ соберётся сам, без ручного набора синтаксиса.

  4. 4. Текстуры (если есть свои картинки)

    Вкладка «Текстуры»: выберите категорию — «Оружие», «Одежда», «Ресурс на земле» или «Другое». Выберите саму вещь из списка (или впишите название, если ещё не добавили) и загрузите PNG — путь textures/… конструктор соберёт сам, по правилам игры (например Guns/kylysh/kylysh-right.png или char/hat/3_down.png). Если своих картинок нет — просто оставьте поле spriteId у оружия/одежды: вещь будет рисоваться как заданная там.

    Рисуйте PNG с прозрачным фоном, пиксель-артом. Путь у любого загруженного файла всегда можно поправить вручную в списке ниже, если конструктор угадал не так.

  5. 5. Проверьте перевод

    Вкладка «Перевод» уже заполнена черновиками (транслитерацией) — пробегитесь и поправьте на нормальный английский, где важно.

  6. 6. Экспорт

    Вкладка «Экспорт» → сначала «Проверить JSON» — конструктор сам укажет, если что-то важное забыто (не открыто технологией, нет пути у текстуры и т.п.). Затем «Скачать мод (.zip)».

    Скачанный архив можно сразу опубликовать на сайте — форма загрузки принимает его без изменений.

  7. 7. Установка в игре

    В игре: Меню → МОДЫ → ВЫБРАТЬ ФАЙЛ → выбрать скачанный .zip.

Работа сохраняется в браузере автоматически — вкладку можно закрывать и возвращаться позже. Кнопки «Сохранить проект» / «Загрузить проект» слева — для переноса на другой компьютер или резервной копии.

Информация о моде

Эти поля попадут в mod.json — карточку вашего мода в списке модов.

Оружие 0

Таблица weapons.json → weapons. Ключ записи — id. Не открытое техом оружие в игре не появится.

Материалы клинков 0

Таблица weapons.json → materials. Ключ — key. Нужны только для оружия с family: true.

Одежда и броня 0

Таблица apparel.json → apparel. Ключ — id. Порядок записей = порядок в окне станка.

Ресурсы 0

Таблица resources.json → resources. Ключ — id. Совпал с игровым — правите его; новый — заводите свой вид.

Рецепты станков 0

Таблица recipes.json → recipes. Ключ — пара station + id. Для оружия-семейств и одежды рецепты создаются автоматически, писать их вручную не нужно.

Постройки 0

Таблица buildings.json → buildings. Ключ — kind + variant. Эта таблица не создаёт постройки, а только меняет числа у существующих.

Технологии 0

Таблица techs.json → techs. Ключ — id. Именно тех выдаёт доступ к вещам — без него вещь есть в таблице, но её нигде нельзя сделать.

Черты, биографии, имена

Таблица pawns.json. Самая безопасная для мода — черты хранятся в сохранении именами.

Черты характера 0

Взаимоисключающие пары черт 0

Детские биографии 0

Взрослые биографии 0

Редкие пары «имя + фамилия» 0

Списки имён

События 0

Таблица events.json → events. Письмо игроку посреди партии. Либо «Последствия», либо «Выбор из двух вариантов» — не оба сразу.

Растения 0

Таблица plants.json → plants. Ведёт себя как ягодный куст: помечают на сбор, колонист собирает, растение отрастает.

Дикие звери 0

Таблица animals.json → animals.

Домашний скот 0

Таблица livestock.json → livestock. Ключ — species. Пустое поле = «оставить как есть», поэтому для правки хватит одной строки.

Мебель и станки 0

Таблица furniture.json → furniture. В отличие от «Построек», эта таблица ДОБАВЛЯЕТ постройки: поле «Основа» берёт поведение игровой постройки, а имя, картинку, цену и прочность задаёте вы.

Державы 0

Таблица factions.json → factions. Ключ — name. Правки игровых держав применяются только в новой игре.

Биомы 0

Таблица biomes.json → biomes. Новый биом добавить нельзя — настраиваются существующие пять.

Заказы держав 0

Таблица quests.json → quests. Только поставка; заказы дают дружественные державы.

Потребности 0

Таблица needs.json → needs. Новая шкала у колониста: убывает сама, портит настроение при падении.

Рассказчики 0

Таблица storytellers.json → storytellers. Задаёт ритм партии.

Испытания 0

Описания «?» 0

Файл info.json → entries: ключ записи → текст.

Английский перевод 0

Файл loc.json. Ключ — ровно та русская строка, что написана в таблице, символ в символ.

Текстуры 0

Выберите, для чего картинка, назовите вещь — путь в textures/ конструктор соберёт сам, по правилам игры.

Все загруженные файлы 0

Путь у любого файла можно поправить вручную — на всякий случай, если конструктор угадал не так.

Собрать мод

Конструктор упакует все заполненные таблицы, mod.json и папку textures в один архив, готовый к установке через Меню → МОДЫ → ВЫБРАТЬ ФАЙЛ.

Единственное, что обязательно писать самим

  • id и название мода — вкладка «Мод»
  • «Название» у каждой новой записи (оружие/одежда/ресурс/рецепт/тех) — остальное можно оставить пустым или взять из шаблона

id вещей, черновой перевод и привязку к технологиям конструктор подставляет сам — кнопка «Проверить JSON» ниже покажет, если что-то всё же забыто.
